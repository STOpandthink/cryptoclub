# Setup

Install python (latest version). Use: https://docs.python.org/3/using/mac.html
Then follow the instructions below to install `backtesting` (for doing strategy backtests and graphing) and `jupyterlab` for using Jupyter notebooks.

```
python3 -m pip install backtesting, jupyterlab, yfinance
```

Now you can run jupyter locally: `jupyter lab`  
Which should open a Chrome tab: http://localhost:8888

# Backtesting

Start by copying this tutorial into a new Jupyter notebooks: https://kernc.github.io/backtesting.py/doc/examples/Quick%20Start%20User%20Guide.html
